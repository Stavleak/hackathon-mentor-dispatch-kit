# Репетиция очереди без участников

Все запросы в сценарии вымышлены. Используйте копию шаблонов в закрытом тестовом документе, не рабочую очередь. Для полного прогона нужны два диспетчера, один ментор и руководитель; если людей меньше, назначьте роли по очереди и явно отмечайте смену роли.

## Подготовка

Запишите тестовую дату, часовой пояс и параметры: подтверждение запроса за три минуты, подтверждение ментора за две, сессия 12 + 3 минуты, проверка очереди каждые пять минут. Это предлагаемые настройки, а не норматив. Ментор `M-001` помогает по `tech` на `ru`; `M-002` по `product` на `ru`. Диспетчер `D-A` передаёт очередь `D-B`, руководитель `L-001` решает исключения.

Тестовые времена ниже относительные: `T+00` означает начало, не время реального события. В CSV вносите полные метки тестовой даты. Длинную сессию можно промотать на бумаге; сохраните её логическое время.

## Полный сценарий

| Момент | Ввод ведущего | Ожидаемое действие и проверка |
|---|---|---|
| T+00 | Команда `T-01` просит `tech`: как воспроизвести ошибку без секретов? | `D-A` создаёт номер, ставит себя владельцем, срок подтверждения и действие |
| T+01 | Команда дала безопасный пример; `M-001` занят ещё 10 минут | Подтверждён номер, вопрос `queued`, записан `queued_at`; не обещать немедленную встречу |
| T+02 | Команда `T-02` просит `product`; `M-002` свободен | Назначается `T-02`, несмотря на более ранний технический запрос; причина `skill_mismatch` записана |
| T+03 | Та же `T-01` присылает запрос через резервный канал | Диспетчер связывает дубликат с прежним номером, не добавляет вторую позицию |
| T+04 | `T-03` просит `tech`, вопрос готов | Новая строка следует после `T-01` по `queued_at` |
| T+05 | Нужен специалист по `hardware`, никто не подтверждён | `needs_route`, владелец `D-A`, конкретная проверка резерва и срок сообщения команде |
| T+11 | `M-001` освободился | Назначается `T-01`, `T-03` ждёт. До подтверждения ментора владелец диспетчер |
| T+13 | Ментор не отвечает | Возврат `T-01` в `queued` с прежним `queued_at`; ментор исключён из доступных до связи |
| T+14 | Руководитель подтверждает другого технического ментора | Вновь выбирается `T-01`, а не `T-03`; фиксируются новое назначение и принятие |
| T+15 | `D-A` предлагает передать очередь; `D-B` молчит | У открытых передач остаётся прежний владелец. Отправка сообщения не считается принятием |
| T+17 | Срок передачи истёк | `D-A` обращается к `L-001`, фиксирует действие и остаётся ответственным |
| T+18 | `D-B` прочитал все открытые номера и подтвердил их | Передача записана, новые сроки и действия заполнены, права записи переходят одному диспетчеру |
| T+19 | Интернет выключен, поступает ещё один вопрос | Резервная бумажная карточка получает номер, время и владельца; участнику выдан номер |
| T+21 | Интернет вернулся, бумажный вопрос есть и в чате | Перенос один раз, основной номер сообщён, источник и объединение записаны |
| T+29 | Техническая сессия закончена, команде нужна самостоятельная проверка | Заполнен итог, согласованы ответственный и время; `team_action` с владельцем-диспетчером либо `closed/action_agreed` по явному выбору команды |
| T+30 | `T-03` всё ещё готова и ждёт; `T-01` уже принесла результат | Следующей назначается `T-03`; повторная помощь `T-01` имеет новый раунд и `queued_at`, прежняя позиция не сохраняется |
| Финал | Очередь закрывается | Каждый открытый запрос имеет сообщённый исход или явную приватную передачу в последующий процесс; нет закрытия только по окончанию смены |

## Сокращённый прогон для быстрого старта

За три минуты проговорите `T+00`, `T+02`, `T+15` и `T+18`: два разных вопроса, свободный ментор по одной теме, уходящий диспетчер и подтверждение. Проверьте одну запись полностью: код, состояние, владелец, срок и следующий шаг. Для проверки таймаута используйте учебный скачок времени и проверьте сохранение прежнего владельца. Полный прогон проведите до настоящего открытия очереди.

## Условия принятия

- [ ] Каждый запрос из обоих каналов сопоставлен номеру; дубликат не даёт второй позиции.
- [ ] Каждое назначение соответствует теме и языку, один ментор не занят дважды.
- [ ] В пределах совместимых запросов порядок соответствует `queued_at` и номеру; исключения имеют причину.
- [ ] После таймаута ментора ранний запрос сохранил позицию.
- [ ] После сессии повторный запрос получил новый раунд; никто не получил бесконечный слот.
- [ ] Отсутствие подходящего ментора привело к честному сообщению и сроку проверки.
- [ ] До подтверждения передачи владельцем оставался прежний человек.
- [ ] Бумажная запись перенесена один раз; идентификаторы не столкнулись.
- [ ] В каждом открытом состоянии заполнены владелец, срок и действие.
- [ ] В публичном статусе нет команд, вопросов, контактов и закрытых ссылок.

Если хотя бы одно условие не выполнено, исправьте инструкцию или доступы и повторите именно этот шаг. Запишите дату прогона, роли, проверенные шаги и незакрытые замечания в закрытые настройки события.

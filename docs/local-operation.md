# Запуск и рабочие данные

Установите зависимости и выполните команды из README в корне этого репозитория. Не запускайте пакет из родительского workspace. `pnpm dev` запускает Next.js на 127.0.0.1:3005 и Rust API на 127.0.0.1:3006; `pnpm start` делает то же для собранного интерфейса и release-сборки Rust. Для остановки нажмите Ctrl+C.

## Доступ

`pnpm setup` создаёт `.env.local` только при его отсутствии. Общий пароль предназначен для доверенной локальной смены; вход действует 8 часов. Это не отдельные учётные записи, роли или журнал действий каждого человека. Не публикуйте порты в интернет и не открывайте доступ недоверенным пользователям. Rust слушает только loopback, принимает Bearer-ключ; интерфейс хранит этот ключ только на сервере и проверяет сессию и Origin перед записью.

Для смены пароля остановите приложение и измените APP_PASSWORD в `.env.local`; задайте новый случайный APP_SESSION_SECRET длиной не менее 32 символов, чтобы завершить старые сессии. Никогда не используйте серверные ключи в NEXT_PUBLIC_ переменных. Конфигурационный пример [.env.example](../.env.example) содержит только пустые значения.

Пять неудачных или успешных попыток входа за минуту ограничиваются одним серверным процессом. Приложение не шифрует диск: доступ к файлам остаётся границей операционной системы. Коды команд и внутренние идентификаторы достаточны; личные контакты храните отдельно.

## Сохранение и восстановление

Сервер сначала проверяет структуру, предметные правила и версию, затем записывает временный файл и заменяет `data/state.json`. Неудача записи оставляет предыдущую версию в памяти. Второй Rust-процесс не может открыть тот же рабочий файл. При повреждённом JSON сервер останавливается, не подменяя его пустыми данными. API принимает набор до 512 КБ.

Для резервной копии остановите оба процесса и скопируйте `data/state.json` в закрытое хранилище. При восстановлении остановите приложение, сохраните текущий файл отдельно, замените его проверенной копией и запустите приложение. Не копируйте рабочие данные в Issues, PR, GitHub или публичные screenshots. Для нового события используйте отдельную копию репозитория с отдельной конфигурацией и набором.

При конфликте вкладок загрузите актуальную версию и повторите действие; приложение не сливает изменения автоматически. На время события назначьте одного ответственного редактора и согласуйте передачу смены через организационные материалы.

## Другие порты

При занятых портах остановите процессы и согласованно измените APP_ORIGIN (например http://127.0.0.1:3105), API_PORT (3106) и API_URL (http://127.0.0.1:3106) в `.env.local`. Скрипт запуска использует APP_ORIGIN для порта интерфейса. Открывайте точно этот адрес: localhost и 127.0.0.1 являются разными Origin.

## Границы версии

Нет интеграции с платформой Stavleak, почтой, чатами, календарями или сторонними API. Статусы доставки и согласия записывает организатор по реальным свидетельствам. Не считайте ручную запись доказательством отправки или личности сама по себе. Учебные данные вымышлены и не являются результатами клиентов.

Исходники приложения и тексты распространяются по MIT; [брендовые файлы и шрифт](../NOTICE.md) имеют отдельные условия.

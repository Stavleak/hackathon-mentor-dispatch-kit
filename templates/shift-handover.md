## Проверка перед подтверждением

- [ ] Оба канала запросов просмотрены; бумажные карточки учтены, дубликаты связаны.
- [ ] Входящий диспетчер открыл актуальную очередь и журнал, понимает часовой пояс.
- [ ] У каждого открытого номера есть один владелец, срок и следующее действие.
- [ ] Просроченные действия перечислены; по каждому есть решение и уведомление команды.
- [ ] Для `queued` сохранены раунд и порядок `queued_at`; неподтверждённые менторы не считаются свободными.
- [ ] Для идущих сессий известны начало, предел слота и ответственный за завершение.
- [ ] Для `needs_route` известен резервный вариант либо честный срок следующего ответа.
- [ ] Для каждой отдельной передачи есть подтверждение нового владельца или прежний владелец продолжает отвечать.
- [ ] Подтверждены фактические часы и темы менторов новой смены; незакрытые конфликты переданы руководителю приватно.
- [ ] Участники получили сообщение, куда писать после смены.
- [ ] Уходящий прекратил редактирование, входящий получил права записи. Два человека не пишут одновременно.
- [ ] Входящий подтвердил принятие всех перечисленных открытых номеров; время и оба кода записаны в журнал.
